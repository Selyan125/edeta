# Edeta

### Edeta est une application mobile développée avec la technologie Compose Multiplatform

Elle permet aux étudiants de voir plus facilement leurs cours via une application mobile.

> [!WARNING]
> Edeta est pour le moment développée pour la filière "Informatique" du BUT **uniquement**.


> [!CAUTION]
> La version debug sera obsolète à partir de la version <ins>**2.0**</ins>. La version release, optimisée pour la production, devra être utilisée à la place.
